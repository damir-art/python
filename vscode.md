# Как работать в VS Code с Python

## 1. 📂 Открой папку `python_lab` в VS Code:
* Запусти VS Code.
* Меню: **File → Open Folder…**
* Выбери папку `D:\python_lab`
* Нажми **"Выбрать папку"**.

## 2. 📄 Создай файл (например, `hello.py`)
* В левой колонке VS Code нажми `New File`.
* Назови файл: `hello.py`
* Напиши:

```python
print("Привет, Даян!")
```

## 3. 🧪 Запусти файл
### 🟢 Способ 1 (через кнопку Play):
* Над кодом появится зелёная кнопка **▶ Run Python File** — нажми на неё.
* Если кнопки нет, то нужно поставить расширение `Python (by Microsoft)` (см. ниже)

### 🟡 Способ 2 (через встроенный терминал):
* Нажми `Ctrl + ~` (тильда) или `View → Terminal`
* Внизу откроется терминал
* Убедись, что ты в папке `python_lab`
* Напиши:

```bash
python hello.py
```

### ⚠️ Важно: Если VS Code не распознаёт Python

Установи расширение:
1. Слева нажми иконку квадратов (Extensions)
2. Найди `Python` от Microsoft
3. Установи его.
4. После этого сверху кода появится кнопка Play.
5. Если кнопка не появилась, перезапусти VS COde.

### ℹ️ Если не появляется кнопка Play или VS Code не видит Python

- Проверь, что установлен Python и добавлен в PATH.
- Перезапусти VS Code после установки расширения.
- Открой командную палитру (Ctrl+Shift+P) и выбери **Python: Select Interpreter** — выбери нужную версию Python.
- Если терминал открылся не в нужной папке, напиши:
  ```
  cd D:\python_lab
  ```
