# Массивы (list - списки)
Переходим к **массивам** — в Python они называются **списки** (`list`). Это, по сути, одна из самых мощных и часто используемых структур данных.

---

## 🔹 Что такое список (list) в Python?

Список — это **упорядоченная изменяемая коллекция объектов**.

```python
fruits = ["яблоко", "банан", "вишня"]
```

📌 Он может хранить любые типы: строки, числа, булевы, даже другие списки.

---

## 🔸 Как создавать списки

```python
empty = []  # пустой список
nums = [1, 2, 3, 4]
mixed = [1, "текст", True, 3.14]
```

---

## 🔸 Доступ к элементам по индексу

Индексация начинается с **нуля**:

```python
fruits = ["яблоко", "банан", "вишня"]
print(fruits[0])  # яблоко
print(fruits[-1]) # вишня (обратный индекс)
```

---

## 🔸 Изменение элементов

```python
fruits[1] = "груша"
print(fruits)  # ['яблоко', 'груша', 'вишня']
```

---

## 🔸 Добавление элементов

```python
fruits.append("ананас")      # добавляет в конец
fruits.insert(1, "персик")   # вставляет по индексу
```

---

## 🔸 Удаление элементов

```python
fruits.remove("груша")     # по значению
del fruits[0]              # по индексу
popped = fruits.pop()      # удаляет и возвращает последний
```

---

## 🔸 Длина списка

```python
print(len(fruits))
```

---

## 🔸 Перебор списка (вот тут пригодятся циклы!)

```python
for fruit in fruits:
    print(fruit)
```

---

## 🔸 Проверка наличия элемента

```python
if "яблоко" in fruits:
    print("Есть яблочко!")
```

---

## 🔸 Сортировка и разворот

```python
numbers = [4, 1, 3, 2]
numbers.sort()      # [1, 2, 3, 4]
numbers.reverse()   # [4, 3, 2, 1]
```

---

## 🔸 Списки списков

```python
matrix = [
    [1, 2],
    [3, 4]
]
print(matrix[1][0])  # 3
```

---

## 🔸 Генератор списков (list comprehension)

```python
squares = [x**2 for x in range(5)]
print(squares)  # [0, 1, 4, 9, 16]
```

---

## 🔹 Коротко: список — это как коробка, в которую ты можешь закидывать всё, что угодно, сколько угодно раз, и потом доставать, менять, сортировать, проверять и перебирать. Удобнейшая вещь!

### Что можно улучшить:
- **Добавить примеры копирования списка** (важно для понимания, что `a = b` — это не копия, а ссылка).
- **Пояснить методы `extend`, `clear`, `count`, `index`** — часто используются.
- **Добавить пример срезов** (slice): как получить часть списка.
- **Указать, что сортировка работает только для сравнимых типов** элементы должны быть одного типа.
- **Добавить предупреждение о изменяемости списков** (например, при передаче в функцию).

### Пример дополнения:

## 🔸 Копирование списка

```python
a = [1, 2, 3]
b = a           # это не копия, а ссылка!
c = a.copy()    # вот так — копия
```

---

## 🔸 Срезы (slice)

```python
nums = [0, 1, 2, 3, 4]
print(nums[1:4])   # [1, 2, 3]
print(nums[:3])    # [0, 1, 2]
print(nums[-2:])   # [3, 4]
```

---

## 🔸 Другие полезные методы

```python
fruits.extend(["слива", "апельсин"])  # добавить несколько
fruits.clear()                        # очистить список
print(fruits.count("яблоко"))         # сколько раз встречается
print(fruits.index("банан"))          # индекс первого вхождения
```

---

## ⚠️ Важно: списки — изменяемые!

Если передать список в функцию, он может измениться внутри неё.

Вот пояснение с примером:

Если список передать в функцию, и внутри функции его изменить, то он изменится и снаружи — потому что передаётся ссылка на объект, а не копия.

```python
def add_item(lst):
    lst.append(100)

numbers = [1, 2, 3]
add_item(numbers)
print(numbers)  # [1, 2, 3, 100]
```

В этом примере функция `add_item` добавляет элемент в список, и исходный список тоже меняется.  
Если нужно сохранить оригинал — используйте копию: `add_item(numbers.copy())`.
