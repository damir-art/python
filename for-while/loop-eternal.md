# Вечный цикл
`while` может превратиться в бесконечный ад, особенно если забыть обновить условие выхода или ошибиться в логике. Но! Есть **заслоны**, которые помогут держать это чудовище под контролем:

```python
while True:
    print("Я никогда не остановлюсь!")
```

---

## 🛡️ Способы защититься от бесконечного `while`

### 1. **Лимит на количество итераций**

Простой, грубый, но действенный способ:

```python
i = 0
max_iterations = 1000

while условие and i < max_iterations:
    # действия
    i += 1
```

> 🔒 Если `условие` не прекращается — всё равно выйдешь после 1000 шагов.

---

### 2. **Добавь `break` по таймеру или другим признакам**

Например, если цикл длится слишком долго:

```python
import time

start = time.time()

while условие:
    if time.time() - start > 5:  # больше 5 секунд
        print("⏰ Слишком долго, выходим!")
        break
```

---

### 3. **Следи за изменяемыми переменными**

99% проблем из-за того, что переменная в условии не меняется:

```python
n = 10
while n > 0:
    print(n)
    n -= 1  # если забудешь это — вечность
```

> 🕵️‍♂️ Всегда следи: **есть ли что-то, что изменяет условие выхода?**

---

### 4. **Используй `else` у `while` для контроля**

Мало кто знает, но `while` может иметь `else`, который сработает **если цикл не завершён через `break`**:

```python
n = 5
while n > 0:
    print(n)
    n -= 1
else:
    print("🎉 Цикл завершился без принудительного прерывания.")
```

---

### 5. **Во время отладки — ставь счётчик защиты**

Пока тренируешься, можно делать так:

```python
i = 0
while True:
    print("Что-то делаю...")
    i += 1
    if i > 100:
        print("🛑 Защита от дурака: прерываем.")
        break
```

Использовать встроенные средства IDE (например, остановку по времени или количеству итераций).

---

## 🚨 И главное правило:

**Если можно не использовать `while` — лучше не использовать `while`.**
Обычно `for` над диапазоном или списком безопаснее.

---

## ⚠️ Частые ошибки

- Забыли изменить переменную в условии выхода
- Опечатка в условии (`n = 0` вместо `n > 0`)
- Использование неправильного сравнения (`is` вместо `==`)

## ✅ Альтернатива: используем `for`

```python
for n in range(10, 0, -1):
    print(n)
```
