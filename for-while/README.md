# Циклы
Циклы в Python — это способ **повторять действия**, пока не надоест (или пока не скажешь `stop`). С их помощью можно перебирать списки, ждать нужного условия, делать итерации по диапазону и т.д.

---

## 🔹 Виды циклов в Python:

| Тип цикла | Когда используется                      |
| --------- | --------------------------------------- |
| `for`     | Когда **знаешь**, сколько раз повторять |
| `while`   | Когда **не знаешь**, но есть условие    |

---

## 🔸 Цикл `for`

Идеален для списков, строк, диапазонов и всего, что можно "перебрать".

```python
fruits = ["яблоко", "банан", "вишня"]

for fruit in fruits:
    print(fruit)
```

🔁 Можно использовать `range()`:

```python
for i in range(5):
    print(i)
```

### `range(start, stop, step)`

```python
for i in range(10, 0, -2):
    print(i)  # 10, 8, 6, 4, 2
```

---

## 🔸 Цикл `while`
Выполняется, пока условие — `True`.

```python
count = 0
max_iterations = 1000 # поможет избежать вечного цикла

while count < 3:
    print("Счёт:", count)
    count += 1
```

⚠️ **ОСТОРОЖНО** с `while` — можно случайно зациклиться навечно.

Как с помощью break можно выйти из бесконечного цикла while:

```python
count = 0
while True:
    print("Счёт:", count)
    count += 1
    if count == 3:
        break  # выход из цикла, когда count достигнет 3
```

Еще пример:

```python
while True:
    answer = input("Продолжить? (да/нет): ")
    if answer == "нет":
        break
```

## 🔸 Операторы внутри циклов

| Оператор   | Что делает                                   |
| ---------- | -------------------------------------------- |
| `break`    | Прерывает цикл досрочно                      |
| `continue` | Пропускает текущую итерацию и идёт дальше    |
| `else`     | Выполняется, если цикл не прерван `break`-ом |

> **Пояснение:**  
> Блок `else` после цикла выполняется только если цикл завершился естественно, без `break`.  
> Это удобно, например, для поиска: если элемент не найден — выполнить действие в `else`.

### Пример `break`:

```python
for i in range(5):
    if i == 3:
        break
    print(i)
```

### Пример `continue`:

```python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

### Пример `else`:

```python
for i in range(3):
    print(i)
else:
    print("Цикл завершён!")
```

## 🔸 Вложенные циклы

```python
for x in range(3):
    for y in range(2):
        print(f"x={x}, y={y}")
```

---

## 🔸 Перебор словаря:

```python
user = {"имя": "Даян", "возраст": 30}

for key, value in user.items():
    print(key, ":", value)
```

---

## 🔸 Генератор списков на базе цикла

```python
squares = [x*x for x in range(5)]
print(squares)  # [0, 1, 4, 9, 16]

# Пример с условием: только чётные числа
evens = [x for x in range(10) if x % 2 == 0]
print(evens)  # [0, 2, 4, 6, 8]
```
