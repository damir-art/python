# print()
Функция `print()` — это то, с чего начинается путь любого Python-разработчика. Она просто **выводит на экран** всё, что ты ей даёшь.

## ✅ Синтаксис:

```python
print(что_вывести)
```

Пустой принт возвращает None - ничего.

## 🔗 Три способа склейки текста и переменных

---

### 🥇 Способ 1: **Через запятую `,`**

```python
name = "Даян"
age = 28

print("Меня зовут", name, "и мне", age, "лет")
```

**Плюсы:**
* Автоматически ставит пробелы между элементами
* Можно смешивать строки и числа (не нужно `str()`)

**Минусы:**
* Не даёт полного контроля над форматированием

📤 Вывод:

```
Меня зовут Даян и мне 28 лет
```

---

### 🥈 Способ 2: **Через плюс `+`**

```python
name = "Даян"
age = 28

print("Меня зовут " + name + " и мне " + str(age) + " лет")
```

**Плюсы:**
* Всё как в обычных языках программирования

**Минусы:**
* Нужно вручную конвертировать числа в строки (`str(age)`)
* Сам ставишь пробелы, запятые и т.д.

📤 Вывод:

```
Меня зовут Даян и мне 28 лет
```

---

### 🥉 Способ 3: **f-строка**

```python
name = "Даян"
age = 28

print(f"Меня зовут {name} и мне {age} лет")
```

f-строка - вставляет переменные в строку, не ломая структуру строки.

```python
name = "Даян"
age = 28

print(f"Привет! Меня зовут {name}, мне {age} лет.")
```

f-строка — это способ вставлять переменные прямо внутрь строки, не ломая голову со склеиванием (плюсы, запятые и т.д.).

Она называется так, потому что перед строкой ставится буква f (от "format" — форматировать). f-строки появились в Python 3.6.

Внутри f-строки можно использовать любые выражения, не только переменные.

Можно вычислять:

```python
print(f"Через 5 лет мне будет {age + 5}")
```

Пример экранирования фигурных скобок:

```python
print(f"{{Это не переменная}}")
```

**Плюсы:**
* Самый современный и гибкий способ
* Удобно вставлять переменные, вычисления и даже вызовы функций

📤 Вывод:

```
Меня зовут Даян и мне 28 лет
```

## 🤓 Дополнительно: `end` и `sep`
`print()` умеет настраивать:

* `end` — что ставить **в конце строки** (по умолчанию `\n`)
* `sep` — что ставить **между аргументами**, если их несколько

Примеры:

```python
print("A", "B", "C", sep="-")  # A-B-C
print("Hello", end="🚀")       # Hello🚀
print("World")                 # продолжается с той же строки, потому что у предыдущей строки нет `\n`
```

## 📝 Многострочный вывод

В Python можно выводить сразу несколько строк, используя тройные кавычки (`'''` или `"""`).  
Это удобно для вывода больших текстов или форматирования.

```python
print("""
Привет!
Это пример
многострочного вывода.
""")
```

📤 Вывод:

```
Привет!
Это пример
многострочного вывода.
```
