# Что можно передать в print()
В print() в качестве переменных можно передавать:

* строки (`"Привет"`)
* переменные
* числа
* списки
* функции
* объекты
- классы
- генераторы
- файлы и другие потоки

В `print()` можно передавать **почти всё, что угодно** — ведь Python сам заботится о том, **как это преобразовать в строку**. Сейчас покажу тебе примеры, включая **объекты, функции, классы и генераторы**.

---

## ✅ В `print()` можно передавать:

---

### 1. **Строки, числа, булевые:**

```python
print("Привет", 42, True)
```

📤 `Привет 42 True`

---

### 2. **Списки, кортежи, словари, множества:**

```python
print([1, 2, 3])
print(("a", "b", "c"))
print({"ключ": "значение"})
print({1, 2, 3})
```

📤 `[1, 2, 3]` и т.д.

---

### 3. **Функции (имя или вызов):**

```python
def greet():
    return "Привет от функции"

print(greet())         # вызов функции → Привет от функции
print(greet)           # ссылка на объект → <function greet at 0x...>
```

---

### 4. **Классы и объекты:**

```python
class Human:
    def __init__(self, name):
        self.name = name

person = Human("Даян")
print(person)  # по умолчанию: <__main__.Human object at 0x...>
```

Если хочешь, чтобы объект красиво выводился — переопредели метод `__str__()`:

```python
class Human:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Человек по имени {self.name}"

print(Human("Даян"))  # Человек по имени Даян
```

Есть еще __repr__ см в папке method

---

### 5. **Генераторы и итераторы:**

```python
gen = (x * x for x in range(5))
print(gen)  # <generator object...>

print(list(gen))  # [0, 1, 4, 9, 16]
```

---

### 6. **None (ничего):**

```python
print(None)  # Выведет: None
```

---

### 7. **Модули, функции, типы:**

```python
import math
print(math)        # <module 'math' from ...>
print(type(123))   # <class 'int'>
print(len)         # <built-in function len>
```

---

### 8. **Файлы и другие потоки:**

```python
f = open("example.txt", "w")
print("Записываю в файл", file=f)
f.close()
```

📌 `file=` — передаёт вывод в файл вместо терминала.  
Главное чтобы файл был открыть для записи, а не чтения.

## Вывод в поток ошибок
Для логирования ошибок.

```python
import sys
print("Ошибка!", file=sys.stderr)
```

---

## 🧠 Вывод:

Да, `print()` — это настоящий **универсал**, потому что он:

* принимает любое количество аргументов
* приводит всё к строковому виду через `str()` (или `repr()` в некоторых случаях)
* автоматически разбирается, как это показать

print() поддерживает Unicode, и если возникают ошибки с кодировкой, стоит проверить настройки среды.

Вывод без переноса строки:

```python
for i in range(3):
    print(i, end=' ')
# 0 1 2
```
