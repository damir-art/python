# Аналоги print()
Функция `print()` — это просто верхушка айсберга. В Python есть **аналогичные и альтернативные способы вывода**, и у каждого — своя фишка 🎯

---

## 🔧 Основной: `print()`

Ты его уже знаешь. Он:
* пишет в **стандартный вывод (stdout)** — обычно это терминал
* по умолчанию добавляет `\n` в конце (новая строка)
* можно управлять `sep`, `end`, и `file`

---

## 🔁 Альтернативы и аналоги:

---

### 1. 🔹 `sys.stdout.write()`

```python
import sys
sys.stdout.write("Привет")
```

**Отличия от `print()`**:

* Не добавляет `\n` в конце!
* Требует явно писать `\n`, если хочешь новую строку
* Чуть быстрее, особенно в циклах

📌 Используется, когда нужно **более точный контроль над выводом**, особенно при большом количестве текста.

---

### 2. 🔹 `logging` — для журналирования

```python
import logging
logging.basicConfig(level=logging.INFO)
logging.info("Программа запущена")
```

**Запись логов в файл:**

```python
import logging
logging.basicConfig(filename="app.log", level=logging.INFO, encoding="utf-8")
logging.info("Это будет записано в файл app.log")
```


**Зачем?**

* Вместо простого `print()` — для реальных программ
* Делит сообщения по уровням (`debug`, `info`, `warning`, `error`, `critical`)
* Можно записывать в файл, а не на экран

📌 Это **“продвинутый print()”** для отслеживания, что происходит в приложении.

---

### 3. 🔹 `input()` — не для вывода, а для **взаимодействия**

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

Хотя это **не аналог `print()`**, но они часто идут **в паре**: один спрашивает, другой отвечает.

Можно добавить, что input() всегда возвращает строку, и для чисел нужно преобразование:

```python
age = int(input("Сколько тебе лет? "))
```

---

### 4. 🔹 `repr()` vs `str()` — форматированный вывод объектов

```python
x = "Привет"
print(str(x))   # человекочитаемо
print(repr(x))  # технически точно: 'Привет'
```

📌 Используются в `debug`, чтобы понимать **как реально устроены переменные**

---

### 5. 🔹 `pprint` — красивый вывод сложных структур

```python
from pprint import pprint

data = {"name": "Даян", "skills": ["Python", "HTML", "Сила духа"]}
pprint(data)
```

📌 Очень удобно, когда словарь или список большой и `print()` делает кашу

---

## JSON
json.dumps() - если нужно красиво вывести данные в формате JSON:

```python
import json
data = {"a": 1, "b": 2}
print(json.dumps(data, ensure_ascii=False, indent=2))
```

## 💡 Итого: когда использовать что?

| Способ               | Когда использовать                                   |
| -------------------- | ---------------------------------------------------- |
| `print()`            | Всегда, когда просто хочешь что-то показать          |
| `sys.stdout.write()` | Когда нужен контроль над концом строки, без `\n`     |
| `logging`            | Для серьёзных программ, где важен контроль логов     |
| `pprint()`           | Когда выводишь большие словари, JSON, списки         |
| `repr()` / `str()`   | Для отладки, чтобы увидеть “внутренности” переменных |
