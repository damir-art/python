# 🔍 Что такое Flask и для чего он нужен

Flask — один из самых популярных Python-фреймворков для создания веб-приложений. Давай начнём по порядку.

**Flask** — это легковесный микрофреймворк для создания веб-приложений на Python. Он минималистичный, но гибкий, и идеально подходит, если ты хочешь:

* создать сайт или веб-интерфейс для твоего Python-приложения (например, для SEO-анализатора),
* сделать REST API (например, чтобы фронт на JavaScript мог обращаться к твоим данным),
* разработать простое админ-панель-приложение, чат, блог, таск-менеджер и пр.

---

## ✅ Когда лучше выбирать Flask

Flask отлично подойдёт, если тебе нужно:

* быстро запустить **прототип** или MVP,
* сделать **небольшое или среднее приложение**,
* иметь **гибкость и контроль** (никаких лишних обвязок),
* учиться веб-разработке на Python с нуля (что мы и делаем 🎓).

---

## 🆚 Flask против других фреймворков

| Особенность                | Flask                                | Django                      | FastAPI                       |
| -------------------------- | ------------------------------------ | --------------------------- | ----------------------------- |
| Уровень сложности          | Низкий, очень просто начать          | Средний (много встроенного) | Средний                       |
| Старт проекта              | Быстро, легко                        | Чуть дольше, много настроек | Быстро                        |
| Гибкость                   | Высокая (ты решаешь всё сам)         | Низкая (много «из коробки») | Средняя                       |
| REST API                   | Нужно делать вручную                 | Нужно делать вручную        | Очень просто и удобно для API |
| Подходит для UI-приложений | Да (можно встраивать шаблоны Jinja2) | Да (всё уже встроено)       | Нет (больше про API)          |
| Документация               | Отличная                             | Огромная и полная           | Отличная, автоген OpenAPI     |

**Вывод**: Flask — это то, что надо для старта и для проектов, где ты хочешь сам контролировать архитектуру.

## 🚀 Установка Flask

Создаём новое виртуальное окружение для проекта:

```bash
python -m venv venv
source venv/bin/activate  # или .\venv\Scripts\activate на Windows
```

Устанавливаем Flask:

```bash
pip install flask
```

Проверяем:

```bash
python -m flask --version
```

## 👶 Первый простой пример приложения

Создаём файл `app.py`:

```python
from flask import Flask  # Импортируем класс Flask из библиотеки flask

# Создаем экземпляр приложения Flask. __name__ указывает Python, где искать ресурсы (шаблоны, статические файлы и т.д.)
app = Flask(__name__)

# Декоратор @app.route("/") регистрирует функцию hello как обработчик для главной страницы (корня сайта)
@app.route("/")
def hello():
    # Возвращаем текст "Привет, Flask!" в ответ на HTTP-запрос к корню сайта
    return "Привет, Flask!"

# Эта конструкция позволяет запускать приложение только если файл запущен напрямую, а не импортирован как модуль
if __name__ == "__main__":
    # Запускаем встроенный сервер Flask в режиме отладки (debug=True) режим разработчика
    app.run(debug=True)
```

Режим разработчика (debug=True), который:
- автоматически перезапускает сервер при изменениях в коде;
- показывает ошибки прямо в браузере, если что-то сломается;
- включает «интерактивный дебаггер».

Запускаем:

```bash
python app.py
```

Открываем в браузере: [http://127.0.0.1:5000/](http://127.0.0.1:5000/)

Сообщения после запуска см 1.png:
- 👉 Ты запустил файл app.py — всё правильно.
- Flask говорит: «Я вижу приложение с именем app». Это потому что ты создал объект `app = Flask(__name__)` в файле app.py.
- 👉 У тебя включён режим разработчика (debug=True)
- Красным:
  - Это не ошибка, а просто предупреждение (поэтому красным):
  - Flask говорит: «Это не настоящий сервер, а учебный, для разработки».
  - В продакшене используют что-то вроде gunicorn или uWSGI + nginx, но тебе сейчас это вообще не нужно.
- Вот это главное: сайт работает по адресу http://127.0.0.1:5000/
  - Открой это в браузере — и ты увидишь свой текст "Привет, Flask!"
- Нажми Ctrl + C, чтобы остановить сервер.
- 👉 Flask следит за файлами. Если ты изменишь app.py, он автоматически перезапустится — удобно!
- Дебаггер включён — ты можешь даже смотреть переменные и стек вызовов при ошибках. Это крутая фича.
- 👉 Безопасность. Этот PIN нужен, если захочешь взаимодействовать с дебаггером через браузер. Игнорируй пока.

## Меняем порт при необходимости
Абсолютно верно, красавчик — на порту `5000` часто висят другие локальные сервисы, например, **Gulp**, **Webpack Dev Server**, **Vite** или **React App**. Но не переживай: у Flask можно легко **поменять порт** на любой другой, хоть на `7777`, хоть на `1337`.

---

## 🔧 Как изменить порт у Flask

Просто добавь аргумент `port=...` в `app.run()`:

```python
if __name__ == "__main__":
    app.run(debug=True, port=7777)
```

### Дополнительно (если нужно):

* `host='0.0.0.0'` — чтобы сервер был доступен извне (например, с телефона по Wi-Fi);
* `use_reloader=False` — если не хочешь автоматической перезагрузки;
* `threaded=True` — включение многопоточности.

Пример с изменением всего:

```python
app.run(debug=True, host='0.0.0.0', port=7777, use_reloader=True)
```

---

## ⚠️ На что обратить внимание

* Не выбирай порты, занятые системными службами (`80`, `443`, `22` и т.д.);
* Лучше использовать порты выше `1024`, например: `3000`, `8000`, `8080`, `8888`, `5001`, `5050`, `5500` и т.д.;
* Если на новом порту ничего не открывается — возможно, его блокирует брандмауэр или VPN.
