# GET / POST
Если мы хотим сделать **блог** — даже самый простой, где можно **добавлять посты** — без понимания `GET` и `POST` во Flask нам никуда.

---

## 🚦Что такое GET и POST?

Это методы, с помощью которых **браузер и сервер обмениваются данными**:

| Метод  | Что делает        | Пример                        |
| ------ | ----------------- | ----------------------------- |
| `GET`  | Получает данные   | Открытие страницы блога       |
| `POST` | Отправляет данные | Отправка формы с новым постом |

---

## 🧠 Как это выглядит во Flask?

### GET-запрос:

```python
@app.route("/blog")
def show_blog():
    return render_template("blog.html")
```

Ты просто открыл страницу в браузере — значит это `GET`.

---

### POST-запрос (например, отправка формы):

```python
@app.route("/add-post", methods=["GET", "POST"])
def add_post():
    if request.method == "POST":
        title = request.form["title"]
        content = request.form["content"]
        # Здесь можно сохранить в список, файл, базу данных и т.п.
        return f"Пост добавлен: {title}"
    return render_template("add_post.html")
```

* Если ты просто заходишь на `/add-post`, то это `GET`, и ты увидишь форму.
* Если нажал кнопку "Добавить" — форма отправляется как `POST`, и Flask её обрабатывает.

---

## 🔥 Что нужно знать для блога?

| Что                                        | Обязательно? | Зачем                                               |
| ------------------------------------------ | ------------ | --------------------------------------------------- |
| `@app.route(..., methods=["GET", "POST"])` | ✅            | Чтобы обрабатывать форму добавления поста           |
| `request.form[...]`                        | ✅            | Чтобы вытащить данные из формы                      |
| Списки/базы данных                         | 🟡           | Чтобы хранить посты (сначала можно просто в список) |
| Jinja2                                     | ✅            | Чтобы отрисовать список постов                      |

## 🔥 1. Что такое `GET` и `POST` во Flask?

### `GET` — запрос на **получение данных** (открытие страниц, загрузка контента)

```python
@app.route("/hello")
def hello():
    return "Привет! Это GET-запрос"
```

Когда ты вбиваешь в адресной строке `/hello` — браузер шлёт `GET`-запрос.

---

### `POST` — запрос на **отправку данных** (например, из формы)

```python
@app.route("/submit", methods=["POST"])
def submit():
    return "Ты отправил POST-запрос!"
```

Такой запрос не получится просто открыть в браузере — его делает **форма или скрипт**, а не ты вручную.

---

## 🛠️ 2. Внедрим в твой Flask-проект

Создадим **один маршрут**, который будет реагировать **и на GET, и на POST**.

### 📁 `app.py`

```python
from flask import Flask, request, render_template

app = Flask(__name__)

@app.route("/")
def index():
    return render_template("index.html")

@app.route("/form", methods=["GET", "POST"])
def form():
    if request.method == "POST":
        name = request.form["name"]
        return f"Привет, {name}!"
    return render_template("form.html")

if __name__ == "__main__":
    app.run(debug=True)
```

---

### 📄 `templates/form.html` — форма

```html
<!DOCTYPE html>
<html>
<head><title>Форма</title></head>
<body>
    <h1>Введи имя</h1>
    <form method="post">
        <input type="text" name="name" placeholder="Твоё имя">
        <button type="submit">Отправить</button>
    </form>
</body>
</html>
```
