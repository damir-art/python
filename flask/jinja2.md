# Jinja2 шаблонизатор
Ты только что подошёл к одной из **самых мощных фич Flask** — шаблонизатору **Jinja2**. Он прямо встроен во Flask, так что ты его **не видишь в импортах**, но он **работает "под капотом"** при каждом `render_template()`.

---

## 💡 Что такое Jinja2?

**Jinja2** — это язык шаблонов. Он позволяет писать **HTML с вкраплением логики на Python**:

* вставлять переменные,
* делать циклы, условия, наследование шаблонов.

💬 Flask использует Jinja2 **по умолчанию** для всех HTML-шаблонов, которые ты рендеришь через `render_template('index.html')`.

---

## 🔥 Пример базовой работы с Jinja2

### В `app.py`:

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def index():
    return render_template("index.html", username="Даян")
```

### В `templates/index.html`:

```html
<h1>Привет, {{ username }}!</h1>
```

🔍 `{{ username }}` — это **Jinja2-синтаксис**: он вставит значение переменной `username` из Python.

---

## 📌 Основной синтаксис Jinja2

| Что делает            | Пример в шаблоне                          |
| --------------------- | ----------------------------------------- |
| Вставка переменной    | `{{ name }}`                              |
| Условие               | `{% if name %}Привет{% endif %}`          |
| Цикл                  | `{% for item in list %} ... {% endfor %}` |
| Комментарий           | `{# Это комментарий #}`                   |
| Наследование шаблонов | `{% extends "base.html" %}`               |

---

## 🔧 Почему его нет в `import`?

Ты прав — в `app.py` ты **не пишешь `import jinja2`**, потому что Flask:

* уже включает Jinja2 в зависимости (`flask` зависит от `jinja2`);
* автоматически подхватывает шаблоны в папке `templates/`;
* автоматически использует движок Jinja2, когда вызываешь `render_template()`.

Если ты хочешь увидеть его прямо:

```bash
pip show jinja2
```

Ты получишь информацию о пакете — он установлен как зависимость Flask.

---

## ✅ Итого

* Jinja2 — это шаблонизатор, который **отвечает за "магические" {{ переменные }} и {% логика %} в HTML**.
* Он **встроен во Flask**, ты используешь его, когда вызываешь `render_template(...)`.
* Работает на Python-стиле синтаксиса и делает HTML динамичным.
