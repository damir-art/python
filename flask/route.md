# Маршруты
Офигенный вопрос, Даян! 💥 Ты прям в самую суть роутинга во Flask попал. Давай разберёмся подробно, по-простому и с примерами:

---

## 📍 Что такое `@app.route("/")`

Да, это **маршрут (route)** — или по-другому **маршрутизатор**, он говорит Flask:

> "Когда пользователь заходит на определённый URL — вызови вот эту функцию."

Пример:

```python
@app.route("/")
def index():
    return "Привет, мир!"
```

👉 Здесь `"/"` — это корневой путь сайта, то есть `http://127.0.0.1:5000/`
👉 Flask говорит: "Окей, если пользователь пришёл на `/`, я запускаю функцию `index()`"

---

## 🧠 Как это работает под капотом

Когда ты запускаешь приложение (`app.run()`), Flask:

1. Сканирует все `@app.route(...)` в коде.
2. Запоминает: "ага, на `/` нужно вызвать `index()`, а на `/about` — `about()`".
3. Когда приходит HTTP-запрос (например, ты заходишь на `/` через браузер), Flask:

   * ищет совпадение среди всех `@app.route(...)`,
   * запускает соответствующую функцию,
   * берёт результат (обычно HTML или текст) и **отдаёт обратно браузеру**.

---

## 🎯 Пример с двумя маршрутами

```python
@app.route("/")
def index():
    return "Главная страница"

@app.route("/about")
def about():
    return "О проекте"
```

* `/` → вызов `index()`
* `/about` → вызов `about()`

---

## ⚡ Вопрос: А кто запускает `def index()`?

Ты её не вызываешь напрямую. Её вызывает **внутренний механизм Flask**, когда пользователь открывает страницу в браузере.

Примерно как:

```python
если пользователь пришёл на "/":
    вызови функцию index()
    верни результат пользователю
```

## 🚀 Крутые фишки маршрутов

Ты можешь:

### 1. Делать переменные в маршруте:

```python
@app.route("/user/<username>")
def user_profile(username):
    return f"Привет, {username}!"
```

📌 `http://127.0.0.1:5000/user/Даян` → вернёт `Привет, Даян!`

---

### 2. Ограничивать тип переменной:

```python
@app.route("/post/<int:post_id>")
def show_post(post_id):
    return f"Пост № {post_id}"
```

📌 `http://127.0.0.1:5000/post/42` → `Пост № 42`
📌 `http://127.0.0.1:5000/post/abc` → ошибка 404 (т.к. `abc` — не int)

---

## ✨ Вывод:

* `@app.route(...)` — связывает URL с функцией.
* Flask сам вызывает нужную функцию, когда пользователь открывает страницу.
* Внутри этих функций ты можешь возвращать HTML, текст, JSON — что угодно.
