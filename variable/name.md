# Имена переменных
Ты можешь называть переменные как хочешь, но есть правила:

✅ Разрешено:
- Буквы (a-z, A-Z)
- Цифры (но не в начале!)
- Подчёркивания _

❌ Нельзя:
- Начинать с цифры: 2day = "сегодня" ❌
- Использовать спецсимволы: @, $, -, пробелы, точки, запятые и т.д.
- Использовать зарезервированные слова, типа if, for, class и др

Разное:
- Переменные чувствительны к регистру (`myVar` и `myvar` — разные переменные).
- Пробелы в именах переменных запрещены.
- Имена переменных должны быть осмысленными и отражать суть хранимых данных: age, user_name
- Рекомендуется использовать стиль `snake_case` для имён переменных в Python (например, user_name).
- Не использовать слишком короткие или непонятные имена

**Примеры:**
```python
user_name = "Иван"      # Хорошо
user2 = "Петя"          # Хорошо
2user = "Оля"           # Ошибка
user-name = "Катя"      # Ошибка
if = 5                  # Ошибка
```
