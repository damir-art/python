# Переменные в Python
Переменная — это имя и значение.  
Имя - это ярлык, бирка, которое ты даёшь значению, чтобы потом его можно было использовать повторно.

Пример:

```python
x = 5
name = "Даян"
pi = 3.14
```

x - имя переменной, 5 - значение переменной. = - знак присваивания.

```python
a = 10
b = a  # b тоже будет 10
```

Python сначала вычисляет значение справа, а потом присваивает его переменной слева.

- name = "Даян" - строка
- age = 28 - число
- city = "Твой город"
- `#` - комментарий

Вывод переменных:
- print("Меня зовут", name)
- print("Мне", age, "лет")
- print("Я живу в городе", city)

## Переопределение переменных
Переменные можно спокойно переопределять:

```python
x = 10
x = "десять"
print(x) # десять
```

Python — язык с динамической типизацией. Это значит: переменная может изменить тип в любой момент.

## Правильные имена
Вместо x, a1, b2 — используй осмысленные названия:

```python
user_name = "Даян"
user_age = 30
```

Так код проще читать и понимать.

## Множественное присваивание
Примеры множественных присваиваний:

```python
a, b, c = 1, 2, 3
x = y = z = 0  # все три переменные равны нулю
```
