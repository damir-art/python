# Импорты и модули
import, from, as

Импорты и модули — это как доступ к складу с инструментами: хочешь калькулятор, хочешь — веб-браузер, хочешь — генератор случайных чисел. Всё через **модули** и **импорт**.

---

## 🔹 Что такое модуль?

**Модуль** — это просто **Python-файл**, в котором собраны функции, классы, переменные и т.д.

Ты можешь:

* использовать встроенные модули
* установить сторонние
* или писать свои

---

## 🔸 Как импортировать модуль?

```python
import math
```

Теперь ты можешь пользоваться его функциями:

```python
print(math.sqrt(16))  # 4.0
print(math.pi)        # 3.14159...
```

---

## 🔸 Импорт только части модуля

```python
from math import sqrt, pi
print(sqrt(25))
print(pi)
```

---

## 🔸 Импорт с псевдонимом (alias)

```python
import math as m
print(m.sin(m.pi / 2))  # 1.0
```

---

## 🔸 Импорт всех элементов (нежелательно!)

```python
from math import *
print(sin(pi))  # работает, но может затереть другие переменные
```

## 🔸 Установка стороннего модуля через pip

```bash
pip install requests
```

Затем в коде:

```python
import requests
response = requests.get("https://httpbin.org/get")
print(response.text)
```

📌 `pip` — это менеджер пакетов Python, как Play Market для библиотек.

## 🔸 Как создать свой модуль?

Создаёшь файл `my_utils.py`:

```python
# my_utils.py
def say_hello(name):
    return f"Привет, {name}!"
```

В основном файле:

```python
import my_utils

print(my_utils.say_hello("Даян"))
```

📦 Просто клади файл рядом — Python сам найдёт его.

---

## 🔸 Где Python ищет модули?

В `sys.path`. Можешь посмотреть:

```python
import sys
print(sys.path)
```

## 🎓 Кратко:

| Синтаксис                    | Что делает                   |
| ---------------------------- | ---------------------------- |
| `import модуль`              | импортирует весь модуль      |
| `from модуль import X`       | импортирует только нужное    |
| `import модуль as псевдоним` | задаёт короткое имя          |
| `pip install`                | устанавливает внешний модуль |

Вот улучшения и дополнения для вашего файла:

---

**1. Импорт из подпапки (пакета):**

```python
from mypackage import mymodule
```
Если в папке есть файл `__init__.py`, она считается пакетом.

---

**2. Виртуальные окружения:**
Рекомендуется использовать виртуальное окружение для изоляции пакетов:

```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows
```

---

**3. Предупреждение про `from module import *`:**

Использование `from module import *` может затереть имена переменных и функций. Лучше избегать.

---

**4. pip — команда для терминала:**
`pip install` выполняется в терминале, а не в Python-коде.

---

**5. Официальный список стандартных модулей:**
[docs.python.org/3/library/index.html](https://docs.python.org/3/library/index.html)

---

**6. Абсолютный и относительный импорт:**
- Абсолютный: `import package.module`
- Относительный (внутри пакета): `from . import mymodule`

---

**7. После установки стороннего модуля иногда требуется перезапустить интерпретатор.**
