# Операции в Python
## 🔹 **Что такое операция в Python?**

**Операция** — это действие, которое Python выполняет над данными (значениями, переменными, объектами) с помощью **операторов**.

Примеры операций:

* `5 + 3` — операция сложения
* `"Привет" + "!"` — операция склеивания строк
* `x > 10` — операция сравнения
* `not True` — логическая операция

---

## 🔹 **Оператор** — это символ или ключевое слово, с помощью которого выполняется операция.

Например:

* `+` — арифметический оператор сложения
* `==` — оператор сравнения на равенство
* `and` — логический оператор И

---

## 🔹 Операции можно разделить на группы:

| Тип операций                 | Что делают?                                        | Примеры                  |
| ---------------------------- | -------------------------------------------------- | ------------------------ |
| **Арифметические**           | Считают числа                                      | `+`, `-`, `*`, `/`, `**` |
| **Строковые**                | Склеивают, повторяют строки                        | `"a" + "b"`, `"x" * 3`   |
| **Сравнения**                | Сравнивают значения, выдают `True`/`False`         | `==`, `!=`, `<`, `>=`    |
| **Логические**               | Комбинируют булевы значения                        | `and`, `or`, `not`       |
| **Присваивания**             | Задают или обновляют значение переменной           | `=`, `+=`, `*=`, и т.д.  |
| **Проверка принадлежности**  | Проверяют, есть ли элемент в коллекции             | `in`, `not in`           |
| **Проверка тождественности** | Сравнивают, ссылаются ли переменные на один объект | `is`, `is not`           |

---

## 🔸 Проще говоря:

Операции — это **действия**,
операторы — это **инструменты**,
а данные (операнды) — это **то, над чем мы эти действия совершаем**.

Пример:

```python
x = 10
y = 5
z = x + y  # операция сложения (оператор +)
```

---

## 🔹 1. Арифметические операции (для чисел)

| Операция | Пример   | Результат | Пояснение                   |
| -------- | -------- | --------- | --------------------------- |
| `+`      | `3 + 2`  | `5`       | Сложение                    |
| `-`      | `5 - 1`  | `4`       | Вычитание                   |
| `*`      | `4 * 2`  | `8`       | Умножение                   |
| `/`      | `8 / 2`  | `4.0`     | Деление (всегда float!)     |
| `//`     | `9 // 2` | `4`       | Целочисленное деление       |
| `%`      | `9 % 2`  | `1`       | Остаток от деления (modulo) |
| `**`     | `2 ** 3` | `8`       | Возведение в степень        |

```python
a = 10
b = 3
print(a + b)  # 13
print(a / b)  # 3.333...
print(a % b)  # 1
```

---

## 🔹 2. Операции со строками (склейка и умножение)

```python
text = "Привет"
name = "Даян"
print(text + ", " + name + "!")  # Привет, Даян!
print("Ха" * 3)  # ХаХаХа
```

📌 Сложение (`+`) склеивает строки, а умножение (`*`) повторяет их.

---

## 🔹 3. Операции сравнения (всё, что возвращает True или False)

| Операция | Пример   | Результат |
| -------- | -------- | --------- |
| `==`     | `3 == 3` | `True`    |
| `!=`     | `3 != 4` | `True`    |
| `>`      | `5 > 2`  | `True`    |
| `<`      | `1 < 3`  | `True`    |
| `>=`     | `5 >= 5` | `True`    |
| `<=`     | `2 <= 1` | `False`   |

```python
age = 18
print(age >= 18)  # True
```

`<>` - устаревший, не используется в новых версиях Python.
---

## 🔹 4. Логические операции (`bool`)

| Операция | Пример           | Результат |
| -------- | ---------------- | --------- |
| `and`    | `True and False` | `False`   |
| `or`     | `True or False`  | `True`    |
| `not`    | `not True`       | `False`   |

```python
is_adult = True
has_ticket = False
print(is_adult and has_ticket)  # False

is_ready = False
print(not is_ready)  # True
```

and и or не всегда вычисляют оба операнда.
---

## 🔹 5. Операции с `in` и `not in`

```python
"Д" in "Даян"        # True
"Z" not in "Даян"    # True

colors = ["красный", "синий"]
print("зелёный" in colors)  # False
```

---

## 🔹 6. Присваивание с операцией

Вместо:

```python
x = x + 1
```

Можно так:

```python
x += 1  # +=, -=, *=, /=, //=, **= и т.д.
```

---

## 🔹 7. Операции с `is` и `is not`

Не путать с `==`!

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a == c)     # True (содержимое одинаковое)
print(a is c)     # False (разные объекты в памяти)
print(a is b)     # True (один и тот же объект)
```

---

## 🔹 8. Операции с `type()` и `id()`

```python
x = 5
print(type(x))  # <class 'int'>
print(id(x))    # уникальный идентификатор объекта в памяти
```

`id()` - редко нужен на практике.
---

## 🔹 9. Тернарная операция (условное выражение в одну строку)
В других языках можно встретить названия: "conditional expression" или "тернарный оператор".

```python
age = 20
status = "взрослый" if age >= 18 else "ребёнок"
print(status)  # взрослый
```
---

## 🔹 10. Бонус: Оператор `:=` (моржовый оператор 🦭)

Введён в Python 3.8 — позволяет **присваивать значение прямо внутри выражения**:

```python
if (n := len("Даян")) > 3:
    print(f"Длина имени {n} — довольно длинная!")

# Использование в цикле
while (line := input()) != "exit":
    print(f"Ввели: {line}")
```

## del

```python
x = 10
del x  # удаляет переменную
```

## pass
Для пустых блоков.

```python
if True:
    pass  # ничего не делает
```

## lambda
Анонимная функция. Оператор лямбда.

```python
f = lambda x: x * 2
print(f(5))  # 10
```
