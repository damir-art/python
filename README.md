## Проверяем
- Нажми Win + R, введи cmd, нажми Enter.
- В открывшемся окне введи: `python --version`
- Должно появиться `Python 3.13.5`
- Если команда не работает, то перезагрузите компьютер.
- Для выхода из cmd введите "exit"

## Создание первого скрипта
Описать как открыть файл в Блокноте или VS Code.
- Создаем файл `D:\python_lab\hello.py`
- Вводим в него `print("Привет, Даян! Это твой первый Python-код!")`
- Открываем Win + R: cmd
- Переходим на диск `D:`
- Переходим в папку `cd python_lab`
- Запусти программу: `python hello.py`

Далее будем работать в VS Code см `vscode.md`.
