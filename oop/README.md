
# 🧠 Что такое ООП простыми словами?

**Объектно-Ориентированное Программирование (ООП)** — это способ писать код, в котором ты создаёшь **объекты**, отражающие реальные вещи: кота, машину, пользователя, пост в блоге.

Ты создаёшь:

* **Класс** — как **чертёж**
* **Объект** — как **экземпляр** этого чертежа
* **Методы** — как **поведение** объекта
* **Атрибуты** — как **характеристики**

---

## 🔹 Простейший класс и объект

```python
class Cat:
    def meow(self):
        print("Мяу!")

my_cat = Cat()  # создаём объект
my_cat.meow()   # Мяу!
```

---

## 🔸 Конструктор `__init__`

Конструктор — специальный метод, вызывается при создании объекта:

```python
class Cat:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print(f"Мяу, я {self.name}!")

cat1 = Cat("Барсик")
cat1.greet()  # Мяу, я Барсик!
```

### Что такое `self`?

Это **ссылка на текущий объект**. Без него Python не поймёт, к какому "Барсику" ты обращаешься 😸

---

## 🔸 Атрибуты объекта

```python
print(cat1.name)  # Барсик
cat1.name = "Мурзик"
print(cat1.name)  # Мурзик
```

---

## 🔸 Методы

Методы — это **функции внутри класса**, которые работают с `self`.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(f"{self.name} гавкает!")

dog1 = Dog("Шарик")
dog1.bark()
```

## 🔸 Наследование

```python
class Animal:
    def speak(self):
        print("Животное издаёт звук")

class Cat(Animal):
    def speak(self):
        print("Кошка говорит мяу")

a = Animal()
a.speak()  # Животное издаёт звук

c = Cat()
c.speak()  # Кошка говорит мяу
```

---

## 🔸 Полиморфизм

Одинаковый метод `speak()`, но поведение зависит от класса. Это и есть **полиморфизм**.

---

## 🔸 Инкапсуляция

Можно "прятать" внутренности:

```python
class BankAccount:
    def __init__(self):
        self.__balance = 0  # приватный атрибут

    def deposit(self, amount):
        self.__balance += amount

    def show_balance(self):
        print(f"Баланс: {self.__balance}")

acc = BankAccount()
acc.deposit(100)
acc.show_balance()  # Баланс: 100
```

🔒 `__balance` нельзя изменить напрямую.

## 🔸 Магические методы (`__str__`, `__len__`, `__eq__`, `__add__`)

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Пользователь: {self.name}"

u = User("Даян")
print(u)  # Пользователь: Даян
```

## 🔥 Итого: компоненты ООП

| Элемент         | Что это                   |
| --------------- | ------------------------- |
| `class`         | шаблон для объектов       |
| `object`        | экземпляр класса          |
| `__init__`      | конструктор               |
| `self`          | ссылка на текущий объект  |
| `method`        | функция внутри класса     |
| `attribute`     | переменная внутри объекта |
| `inheritance`   | наследование поведения    |
| `encapsulation` | скрытие данных            |
| `polymorphism`  | переопределение методов   |

## 🔸 Магические методы (`__str__`, `__repr__`, `__len__`, `__eq__`, `__add__`)

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Пользователь: {self.name}"

    def __repr__(self):
        return f"User('{self.name}')"

u = User("Даян")
print(u)         # Пользователь: Даян
print(repr(u))   # User('Даян')
```

`__str__` — для пользователя, `__repr__` — для разработчика и отладки.

## 🔸 Наследование с super()

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
```

## 🔸 Абстракция

Абстракция — выделение только важных характеристик объекта, скрытие деталей реализации.

| Элемент         | Что это                   |
| --------------- | ------------------------- |
| `class`         | шаблон для объектов       |
| `object`        | экземпляр класса          |
| `__init__`      | конструктор               |
| `self`          | ссылка на текущий объект  |
| `method`        | функция внутри класса     |
| `attribute`     | переменная внутри объекта |
| `inheritance`   | наследование поведения    |
| `encapsulation` | скрытие данных            |
| `polymorphism`  | переопределение методов   |
| `__repr__`      | техническое представление |
| `abstraction`   | выделение сути            |

См. ___repr___.md для подробностей о `__repr__`.  
Абстракция — один из ключевых принципов ООП, наряду с инкапсуляцией, наследованием и полиморфизмом.
