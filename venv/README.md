# Виртуальная среда
Проект должен быть самодостаточным, переносимым и изолированным.  
Подробнее с примером смотри в course-parsing/0.md

Если **по-взрослому**, по-боевому и по-программистски — то **каждый проект должен жить в своей виртуальной среде**. Это **золотое правило Python-разработки**.

---

## 🧠 Что такое виртуальная среда?

**Виртуальная среда (virtual environment)** — это **изолированная мини-среда Python**, где:

* Свои библиотеки (`requests`, `bs4`, `numpy` и т.д.)
* Свой `pip`
* Всё лежит отдельно от других проектов и от глобальной системы

---

## ❗ Зачем она нужна?

* ✅ Чтобы не конфликтовали версии библиотек
* ✅ Чтобы случайно не сломать глобальный Python
* ✅ Чтобы ты мог отправить проект другу или на сервер — и всё работало один в один

---

## 🛠 Как создать виртуальную среду

### 📍 Шаг 1 — Создать:

```bash
mkdir parser # создаём папку проекта
cd parser # заходим в неё

python -m venv parser_env # создаём вирт среду для прокта
```

Создаст папку `parser_env` со своей мини-копией Python.

В результате получится структура:

```
parser/
├── parser_env/       ← твоя виртуалка
├── parser.py
└── requirements.txt # файл сос писком зависимостей
```

### 📍 Шаг 2 — Активировать:

#### 🔹 Windows:

```bash
parser_env\Scripts\activate
.\parser_env\Scripts\Activate.ps1 # в PowerShell
```

#### 🔹 macOS/Linux:

```bash
source parser_env/bin/activate
```

Увидишь в терминале что-то вроде:

```bash
(parser_env) C:\Users\Даян\projects\my-parser>
```

### 📍 Шаг 3 — Установить модули:

```bash
pip install requests beautifulsoup4 lxml
```

---

## 📦 Сохраняем зависимости:

Чтобы в будущем быстро восстановить окружение:

```bash
pip freeze > requirements.txt
```

А потом в другой системе:

```bash
pip install -r requirements.txt
```

## Деактивация виртуальной среды
Команда для выхода из виртуальной среды:

```bash
deactivate
```

## Удаление виртуальной среды:
Кратко упомянуть, что виртуальную среду можно просто удалить, удалив её папку.

## Совет по .gitignore:
Рекомендовать добавлять папку виртуальной среды в .gitignore:

```
venv/
```

## Совет по версии Python
Указать, что можно явно указать версию Python при создании виртуальной среды:

```bash
python3.11 -m venv venv
```

## Совет по обновлению pip
После создания виртуальной среды полезно обновить pip:

```bash
python -m pip install --upgrade pip
```

## Проверка активной среды

```bash
which python
```

```bash
where python
```

## Удаление среды
На Windows:

```bash
rmdir /s /q parser_env
```

На Linux/macOS:

```bash
rm -rf parser_env
```
