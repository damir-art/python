# Условные конструкции
## 🔹 Что такое условные конструкции?

Это способ сказать Python'у:

> "Если выполнено условие — делай вот это. Если нет — делай что-то другое."

---

## 🔸 Синтаксис `if`, `elif`, `else`

```python
age = 20

if age < 18:
    print("Ты ещё молодой боец 🧒")
elif age < 65:
    print("Ты в расцвете сил! 💪")
else:
    print("Пора на пенсию? 🎩")
```

📌 Важное:

* `:` ставится в конце строки условия
* **всё, что внутри блока, пишется с отступом (обычно 4 пробела или таб)**
* `elif` = "else if"
* `else` — срабатывает, если ничего выше не подошло

---

## 🔸 Вложенные условия (if внутри if)

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Проходи в клуб!")
    else:
        print("Нужен билет!")
else:
    print("Слишком молод!")
```

---

## 🔸 Короткая форма (тернарный оператор)

```python
age = 17
status = "взрослый" if age >= 18 else "несовершеннолетний"
print(status)
```

## 🔹 А где `switch` в Python?

В Python до версии 3.10 не было `switch-case`, как в других языках.
Но с **Python 3.10** появился оператор `match-case`:

### 🔸 Пример:

```python
command = "start"

match command:
    case "start":
        print("Запуск 🚀")
    case "stop":
        print("Остановка ⛔")
    case "pause":
        print("Пауза ⏸️")
    case _:
        print("Неизвестная команда 🤷")
```

🔹 `case _:` — это как `default`

## 🔹 Советы:

✅ Условия можно комбинировать:

```python
if age >= 18 and has_ticket:
    print("Welcome!")
```

✅ Проверка принадлежности:

```python
if fruit in ["яблоко", "банан", "вишня"]:
    print("Это фрукт 🍎")
```

✅ Проверка на пустоту:

```python
if not my_list:
    print("Список пуст!")
```

1. **Пояснить, что `elif` можно использовать сколько угодно раз**.
2. **Добавить пример с логическим оператором `or`**.
3. **Пояснить, что пустые коллекции (`[]`, `{}`, `''`, `set()`) считаются "ложными"**.
4. **Добавить пример проверки типа через `isinstance`**.
5. **Добавить про вложенные условия с elif**.

✅ Логическое "ИЛИ":

```python
if age < 18 or not has_ticket:
    print("Вход запрещён!")
```

✅ Проверка типа переменной:

```python
if isinstance(age, int):
    print("Возраст — это число")
```

✅ Пустые коллекции считаются "ложными":

```python
if not []:
    print("Список пуст!")  # сработает
```

✅ Можно использовать несколько elif:

```python
score = 85
if score >= 90:
    print("Отлично!")
elif score >= 75:
    print("Хорошо!")
elif score >= 60:
    print("Удовлетворительно")
else:
    print("Нужно подтянуть")
```
