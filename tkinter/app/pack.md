# pack()

## 🔍 Что делает `url_entry.pack(pady=40)`?

### 🎒 `pack()` — это **менеджер геометрии**

> “Размести этот виджет (в данном случае `url_entry`) внутри окна `app`... и сделай это **по-простому** — просто вниз по очереди”.

Tkinter и customtkinter используют **менеджеры геометрии**, чтобы размещать элементы в окне.
Есть три таких менеджера:

1. `pack()` — самый простой (используем его сейчас)
2. `grid()` — для размещения по строкам и столбцам (таблично)
3. `place()` — абсолютные координаты (редко используем)

---

## 📦 Синтаксис `pack()`:

```python
widget.pack(
    side="top",     # по умолчанию сверху вниз
    padx=10,        # отступ слева и справа
    pady=20,        # отступ сверху и снизу
    fill="x",       # растянуть по ширине
    expand=True     # занять свободное пространство
)
```

---

## 💡 Конкретно у нас:

```python
url_entry.pack(pady=40)
```

Это значит:

* **размести** элемент `url_entry` в окне
* **сделай вертикальный отступ 40 пикселей сверху и снизу**
* остальное — по умолчанию (`side="top"`, без растяжения)

---

### 🔍 Как это влияет на вид:

Если бы ты поставил `pady=5`, поле бы прижалось к другим элементам.
А `pady=40` даёт приятный “воздух” — визуальный отступ, чтобы интерфейс не выглядел скучным и тесным.
