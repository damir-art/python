# Window

Начинаем закладывать фундамент для **твоего будущего SEO-анализатора** 👨‍💻🔍
Первым делом — сделаем **чистое и красивое окно**, чтобы задать основу: **название, ширину и высоту**.

---

## 🔧 Базовый интерфейс SEO-анализатора

```python
import customtkinter as ctk

# Настройки темы и цвета
ctk.set_appearance_mode("dark")  # можно: "light", "dark", "system"
ctk.set_default_color_theme("blue")  # темы: blue, green, dark-blue (можно создать свой json файл со своими цветами)

# Главное окно
app = ctk.CTk()
app.title("SEO-анализатор")  # Заголовок окна
app.geometry("800x600")      # Размер окна: ширина x высота
app.resizable(False, False)  # Запрет масштабирования (по желанию)

# Запуск
app.mainloop()
```

---

## 📐 Что здесь важно:

| Параметр                  | Значение                    | Комментарий                             |
| ------------------------- | --------------------------- | --------------------------------------- |
| `title("...")`            | "SEO-анализатор"            | Заголовок окна в шапке                  |
| `geometry("800x600")`     | Размер окна                 | Указываем как строку: `"ширинаxвысота"` |
| `resizable(False, False)` | Блокирует изменение размера | Можно включить, если понадобится позже  |

---

## 💡 Дальше что делаем?

Предлагаю такой маршрут:

1. **\[✔]** Название и размеры окна
2. Добавим **поле ввода URL**
3. Кнопку “Анализировать”
4. Вывод заголовка страницы (`<title>`)
5. Затем мета-теги, h1, ссылки и т.д.

---

Если всё ок с окном — давай двигаться к **вводу URL**: сделаем `CTkEntry` и `CTkButton`, красиво разместим их. Сигналь — и поедем 🚗💨
