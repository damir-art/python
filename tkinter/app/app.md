# app
`ctk.CTk()` — это **начало всей жизни интерфейса**.

---

## 🧠 Что делает `app = ctk.CTk()`?

Давай разберём **по кусочкам**:

### 🔹 `ctk`

Это сокращение от `customtkinter`, которое мы импортировали вот так:

```python
import customtkinter as ctk
```

Теперь все виджеты и функции из библиотеки доступны с префиксом `ctk.`
Пример:

* `ctk.CTkEntry`
* `ctk.CTkLabel`
* `ctk.CTkButton`
* и т.д.

---

### 🔹 `CTk`

Это класс из библиотеки customtkinter.
Полное название: **Custom Tkinter Root Window**
Он наследует поведение стандартного `tk.Tk()` — **главного окна приложения**, но делает его:

* с поддержкой тёмной/светлой темы
* с современным дизайном
* с кастомными темами (`set_default_color_theme`)
* с нормальной адаптацией под DPI экрана

---

### 🔹 `app = ...`

Ты просто создаёшь **экземпляр главного окна** и сохраняешь его в переменную `app`.
Это и есть **основа всего GUI** — в него мы “приклеиваем” все остальные компоненты: поля, кнопки, заголовки и т.д.

---

## 🔧 Простой аналогия:

```python
app = ctk.CTk()
```

≈
**“Создай пустое окно, которое мы будем заполнять элементами”**

---

## 📦 А что будет, если этого не написать?

Без этой строки у тебя не будет ни одного окна.
Python не создаст интерфейс — он просто завершит выполнение, потому что не знает, что надо рисовать.

---

## ✍️ Полный минимальный пример:

```python
import customtkinter as ctk

app = ctk.CTk()           # ← вот она, главная строка
app.geometry("400x300")   # задаём размер окна
app.title("Пример")       # заголовок
app.mainloop()            # запуск приложения (обязателен!)
```

---

Теперь, когда у нас есть `app`, мы делаем:

* `CTkLabel(app, ...)`
* `CTkEntry(app, ...)`
* `CTkButton(app, ...)`

👉 То есть все виджеты — **дочерние элементы** этого окна.

---

Готов к следующему элементу? Погнали разбирать **CTkButton** — он у нас будет запускать анализатор 🧨
Скажи только: хочешь кнопку “по центру” или сделать её с иконкой и надписью?
