# Кнопка
Вот мы и подошли к **самому кликабельному** элементу интерфейса — кнопке! 🖱️
Сейчас мы дадим пользователю возможность **что-то запустить, что-то сломать, а может даже что-то распарсить** 😄

---

## 🔘 `ctk.CTkButton` — кнопка из `customtkinter`

Это современная кнопка с:

* поддержкой темы (тёмная/светлая)
* кастомным цветом
* анимацией при наведении
* закруглёнными краями
* возможностью повесить `command` (что произойдёт при клике)

---

## ⚙️ Основные параметры

| Параметр           | Описание                                |
| ------------------ | --------------------------------------- |
| `master`           | Родитель (обычно `app`)                 |
| `text`             | Надпись на кнопке                       |
| `command`          | Функция, вызываемая при клике           |
| `width` / `height` | Размеры                                 |
| `corner_radius`    | Закругление углов                       |
| `fg_color`         | Цвет кнопки                             |
| `hover_color`      | Цвет при наведении                      |
| `text_color`       | Цвет текста                             |
| `font`             | Кортеж (`шрифт`, `размер`, `стиль`)     |
| `image`            | Изображение на кнопке (вместе с `text`) |
| `state`            | `"normal"` или `"disabled"`             |

---

## 🔔 Основное: `command=имя_функции`

Вот она — фишка кнопки. Мы привязываем к ней функцию.
При нажатии — вызывается эта функция.

---

## 🧪 Пример кнопки:

```python
import customtkinter as ctk

def on_click():
    print("Кнопка нажата!")

app = ctk.CTk()
app.geometry("400x200")

button = ctk.CTkButton(app, text="Нажми меня", command=on_click)
button.pack(pady=40)

app.mainloop()
```

### 🔍 Что происходит:

* Кнопка с надписью "Нажми меня"
* При клике в консоли появляется: `Кнопка нажата!`

---

## 🎨 Хочешь стильнее?

```python
ctk.CTkButton(
    master=app,
    text="Анализировать",
    width=200,
    height=40,
    fg_color="#1f6aa5",
    hover_color="#144870",
    text_color="white",
    font=("Arial", 16),
    command=наша_функция
)
```

---

## 🧠 Кнопку можно:

* Отключать: `state="disabled"`
* Менять текст: `button.configure(text="Готово!")`
* Использовать с иконкой: `image=иконка`, `compound="left"`

Готов добавить кнопку в наш интерфейс как **следующий кирпичик**?

Если да, я добавлю:

* `CTkButton` с надписью “Анализировать”
* `command`, который просто выведет `print("Анализируем...")`

Делаем кнопку **по центру**, прямо под полем ввода URL.
Пока она будет просто печатать `"Анализируем..."` — как первый “щелчок жизни” в нашем интерфейсе 🚀

---

## 💡 Как разместить по центру?

Мы используем `pack()` без параметра `side`, а только `pady` — тогда кнопка встанет **по центру горизонтально**, как и все остальные элементы выше.

---

## 🧱 Обновлённый код интерфейса с кнопкой:

```python
import customtkinter as ctk

# Настройка темы
ctk.set_appearance_mode("dark")
ctk.set_default_color_theme("blue")

# Окно
app = ctk.CTk()
app.title("SEO-анализатор")
app.geometry("800x600")
app.resizable(False, False)

# Метка
label = ctk.CTkLabel(app, text="Введите URL для анализа", font=("Arial", 18))
label.pack(pady=(40, 10))

# Поле ввода
url_entry = ctk.CTkEntry(app, placeholder_text="https://example.com", width=500)
url_entry.pack(pady=(0, 20))

# Функция по клику
def analyze():
    url = url_entry.get()
    print(f"Анализируем: {url}")

# Кнопка
analyze_button = ctk.CTkButton(app, text="Анализировать", command=analyze, width=200)
analyze_button.pack(pady=10)

# Запуск окна
app.mainloop()
```

---

### ✅ Что происходит:

* Всё выровнено по центру
* Поле — с placeholder'ом
* Кнопка вызывает `analyze()`, которая просто `print()`'ит URL
