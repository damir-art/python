# Tkinter
О да, Даян, ты подошёл к очень интересному этапу! 🎉 Мы можем начать изучение создания **десктопных приложений на Python** — это прям то, что нужно, чтобы оживить код и сделать его настоящим "приложением с окошками", а не просто текстом в терминале.

---

## 🚀 Что будем изучать?

Есть несколько популярных способов создавать десктопные GUI-приложения на Python. Вот самые удобные:

### 1. **Tkinter** (встроен в Python) — простейший вариант

✅ Подходит для старта
✅ Ничего не надо устанавливать
✅ Много туториалов
❌ Немного старомодно выглядит

### 2. **PyQt / PySide** — мощно, но чуть сложнее

✅ Профессиональный интерфейс
✅ Множество компонентов
❌ Нужно ставить
❌ Учиться дольше

### 3. **customtkinter** — современный стиль + простота Tkinter

✅ Основан на Tkinter
✅ Красивый интерфейс
✅ Просто писать
❌ Нужно установить через pip

## 🔥 Мой план для старта (на 3 дня):

### **День 1 — Tkinter: азы GUI**

* Окно, кнопка, метка
* Событие по нажатию кнопки
* Ввод текста
* Простая логика

### **День 2 — Layout и интерактивность**

* Расположение элементов (pack, grid)
* Несколько окон
* Обработка пользовательского ввода
* Простой мини-проект (например, калькулятор)

### **День 3 — Улучшаем стиль**

* Используем `customtkinter`
* Меняем тему, шрифты, размеры
* Делаем маленькое приложение с несколькими экранами (например, чеклист задач)

---

## 🔧 Что нужно установить?

В первый день — **ничего**, Tkinter уже встроен!
На третий день — понадобится `customtkinter`:

```bash
pip install customtkinter
```
