# def
Функции — это **сердце и мозг кода**. С ними Python становится чистым, повторяемым и мощным. Погнали!

---

## 🔹 Что такое функция?
**Функция** — это блок кода, которому ты даёшь имя и можешь вызывать сколько угодно раз, когда захочешь.

👉 Вместо того чтобы писать один и тот же код 10 раз, ты пишешь его **один раз**, даёшь ему имя — и используешь, когда надо.

---

## 🔸 Объявление функции

```python
def say_hello():
    print("Привет, друг!")
```

Вызов:

```python
say_hello()
```

---

## 🔸 Функция с аргументами

```python
def greet(name):
    print(f"Привет, {name}!")
```

Вызов:

```python
greet("Даян")  # Привет, Даян!
```

---

## 🔸 Функция с несколькими параметрами

```python
def add(a, b):
    return a + b
```

```python
result = add(3, 5)
print(result)  # 8
```

🧠 `return` — возвращает значение наружу (в отличие от `print`, который просто выводит)

---

## 🔸 Аргументы по умолчанию

```python
def greet(name="незнакомец"):
    print(f"Привет, {name}!")
```

```python
greet()            # Привет, незнакомец!
greet("Даян")      # Привет, Даян!
```

## 🔸 Именованные аргументы (keyword arguments)

```python
def show_info(name, age):
    print(f"{name}, возраст: {age}")

show_info(age=25, name="Даян")
```

---

## 🔸 `*args` и `**kwargs`

* `*args` — собирает **все позиционные аргументы**
* `**kwargs` — собирает **все именованные аргументы**

```python
def show_all(*args, **kwargs):
    print("args:", args)
    print("kwargs:", kwargs)

show_all(1, 2, 3, name="Даян", age=30)
```

---

## 🔸 Лямбда-функции (анонимные)

Иногда нужна крошечная функция — на лету:

```python
square = lambda x: x * x
print(square(4))  # 16
```

Лямбда-функции — компактный способ создать функцию без имени.

## 🔸 Область видимости (scope)

```python
x = 10  # глобальная

def test():
    x = 5  # локальная
    print(x)

test()       # 5
print(x)     # 10
```

🔐 Функция не видит переменные вне себя, если не передать их явно. Но видит всё, что внутри себя.

Это верно для локальных переменных, но глобальные переменные доступны для чтения (если не происходит присваивание). Функция может читать глобальные переменные, но не может их изменять без ключевого слова global.

## 🔥 Резюме:

| Что            | Пример            |
| -------------- | ----------------- |
| Объявить       | `def имя():`      |
| Вызвать        | `имя()`           |
| Аргументы      | `def f(x, y=10)`  |
| Вернуть что-то | `return значение` |
| Анон функция   | `lambda x: x * 2` |

---

1. **Возврат нескольких значений**
```python
def get_pair():
    return 1, 2

a, b = get_pair()  # a=1, b=2
```

2. **Докстринг (строка документации)**
```python
def foo():
    """Это пример докстринга."""
    pass
print(foo.__doc__)
```

3. **Ключевое слово `global`**
```python
x = 10
def change():
    global x
    x = 20
change()
print(x)  # 20
```

4. **Кратко про вложенные функции**
```python
def outer():
    def inner():
        print("Внутри!")
    inner()
```

5. **Пример функции с возвратом None**
```python
def do_nothing():
    pass
print(do_nothing())  # None
```
