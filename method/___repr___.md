# __repr__

Этот метод (специальны, магический) не просто влияет на то, **что покажет `print()`**, он ещё и **решает, как твой объект будет "выглядеть глазами Python’а"**. Давай разложим по полочкам:

---

## 🔍 Что такое `__repr__`?

`__repr__` — это **специальный метод**, который отвечает за **"официальное" представление объекта**. Его задача — возвращать **строку**, которая:

> "однозначно описывает объект и по возможности может быть использована для его воссоздания"

📌 Проще говоря:

* `__str__` → для людей
* `__repr__` → для отладки, логов, отрисовки в `print()`, если `__str__` не задан

---

## 🔁 Разница между `__str__` и `__repr__`

```python
class Human:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Меня зовут {self.name}"

    def __repr__(self):
        return f"Human('{self.name}')"

person = Human("Даян")

print(person)        # вызывает __str__ → Меня зовут Даян
print([person])      # список вызывает __repr__ → [Human('Даян')]
```

✅ Если `__str__` нет — Python использует `__repr__`.

---

## 🧪 Пример без `__repr__`

```python
class Thing:
    pass

print(Thing())  
# <__main__.Thing object at 0x...> — бесполезная строка по умолчанию
```

---

## 🧪 Пример с `__repr__`:

```python
class Thing:
    def __repr__(self):
        return "Thing()"

print(Thing())  # Thing()
```

---

## 💥 Где `__repr__` реально полезен?

* В логах, дебаге, `print([объект])`
* В `pprint`, `logging`, `assert`
* В интерактивной консоли:

  ```python
  >>> person
  Human('Даян')
  ```

---

## 🤯 Хитрый приём: `eval(repr(obj))`

Иногда `__repr__` пишут так, чтобы можно было восстановить объект:

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

p = Point(2, 3)
print(repr(p))        # Point(2, 3)
p2 = eval(repr(p))    # работает, если класс доступен
print(p2.x, p2.y)     # 2 3
```

---

## ✨ Итого:

| Метод      | Для кого?    | Что делает                                                      |
| ---------- | ------------ | --------------------------------------------------------------- |
| `__str__`  | Для людей    | Красивый вывод, когда `print(obj)`                              |
| `__repr__` | Для Python'а | Техническое представление, вызывается в списках, логах, отладке |

### 3. Советы по реализации `__repr__`
- Хорошей практикой считается, чтобы `eval(repr(obj))` создавал эквивалентный объект, если это возможно.
- Если это невозможно, `__repr__` должен возвращать информативную строку для отладки.

### 4. Пример с dataclass
Можно показать, что у `dataclass` уже есть удобный `__repr__`:

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(2, 3)
print(repr(p))  # Point(x=2, y=3)
```

### 5. Кратко про `__str__` и `__repr__`
- `__str__` — для пользователя.
- `__repr__` — для разработчика и Python.
