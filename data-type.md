# Типы данных в Python
Python сам определяет тип:

```python
age = 25          # int
name = "Даян"     # str
height = 1.75     # float
is_cool = True    # bool
```

Посмотреть какой тип у переменных:

```python
print(type(age))  # <class 'int'>
```

Вот "золотая семёрка", с которой ты будешь встречаться чаще всего:

| Тип     | Пример              | Описание                     |
| ------- | ------------------- | ---------------------------- |
| `int`   | `5`, `-100`, `0`    | Целое число                  |
| `float` | `3.14`, `-0.01`     | Число с точкой (десятичное)  |
| `str`   | `"Привет"`, `'123'` | Строка (текст)               |
| `bool`  | `True`, `False`     | Булев тип (логический)       |
| `list`  | `[1, 2, 3]`         | Список                       |
| `tuple` | `(1, 2, 3)`         | Кортеж (неизменяемый список) |
| `dict`  | `{"имя": "Даян"}`   | Словарь (ключ + значение)    |

---

## 🔸 1. `int` — Целые числа

```python
a = 10
b = -55
print(type(a))  # <class 'int'>
```

---

## 🔸 2. `float` — Числа с плавающей точкой

```python
pi = 3.14159
temp = -0.5
```

---

## 🔸 3. `str` — Строки (текст)

```python
name = "Даян"
message = 'Привет, мир!'
```

Можно использовать как двойные, так и одинарные кавычки. А также тройные для многострочного текста:

```python
poem = """Это строка
на несколько строк"""
```

---

## 🔸 4. `bool` — Логические значения

```python
is_happy = True
is_sad = False
```

Они особенно полезны в условиях: `if`, `while`, сравнениях и т.д.

---

## 🔸 5. `list` — Списки

Это как коробка, где ты можешь хранить кучу всего:

```python
fruits = ["яблоко", "банан", "вишня"]
print(fruits[0])  # яблоко
```

Можно менять, добавлять, удалять.

---

## 🔸 6. `tuple` — Кортежи

То же, что список, но нельзя изменять:

```python
colors = ("красный", "зелёный", "синий")
```

---

## 🔸 7. `dict` — Словари (ключ: значение)

```python
user = {
    "имя": "Даян",
    "возраст": 25,
    "город": "Алматы"
}
print(user["имя"])  # Даян
```

---

## 🔸 Проверка типа

```python
print(type(42))             # <class 'int'>
print(type("Привет"))       # <class 'str'>
print(type([1, 2, 3]))       # <class 'list'>
```

---

## 🔸 Преобразование типов

Иногда нужно преобразовать один тип в другой:

```python
a = "10"
b = int(a)  # теперь это число
c = str(b)  # снова строка

x = bool(0)     # False
y = bool(1)     # True

print(bool(""))      # False
print(bool([]))      # False
print(bool({}))      # False
print(bool(None))    # False

# Преобразование списка в кортеж и обратно
lst = [1, 2, 3]
tpl = tuple(lst)  # (1, 2, 3)
lst2 = list(tpl)  # [1, 2, 3]

# Преобразование списка в строку
s = ",".join(["a", "b", "c"])  # 'a,b,c'

# Преобразование строки в список
chars = list("hello")  # ['h', 'e', 'l', 'l', 'o']
```

Не все преобразования возможны:

```python
# Ошибка при преобразовании
a = "abc"
b = int(a)  # ValueError: invalid literal for int()
# ...существующий код...
```

Преобразование dict в list/tuple, как получить ключи, значения, пары:

```python
user = {"имя": "Даян", "возраст": 25}
keys = list(user.keys())      # ['имя', 'возраст']
values = tuple(user.values()) # ('Даян', 25)
items = list(user.items())    # [('имя', 'Даян'), ('возраст', 25)]
```
