## 🧱 Урок 4 — **Сохраняем всё в JSON**
Теперь давай сделаем **ещё один шаг к реальному проекту**:
📁 Сохраняем все данные в файл `quotes.json`, чтобы потом использовать их в другом коде, передавать, фильтровать, загружать на сервер — хоть на Марс 🚀

---

## 🎯 Что будем сохранять:

Каждая цитата — отдельный словарь:

```json
{
  "text": "Цитата",
  "author": "Имя",
  "tags": ["tag1", "tag2"],
  "born_date": "Дата рождения",
  "born_location": "Где родился"
}
```

---

## 🔥 Полный код Урока 4 с комментариями:

```python
import requests
from bs4 import BeautifulSoup
import json  # модуль для работы с JSON-файлами

base_url = "http://quotes.toscrape.com"
page_url = "/page/1"
visited_authors = {}
all_quotes = []

while page_url:
    response = requests.get(base_url + page_url)
    soup = BeautifulSoup(response.text, "lxml")

    quotes = soup.find_all("div", class_="quote")

    for quote in quotes:
        text = quote.find("span", class_="text").text
        author = quote.find("small", class_="author").text
        tags = [tag.text for tag in quote.find_all("a", class_="tag")]

        author_link = quote.find("a")["href"]

        # Если этого автора мы ещё не парсили — парсим и сохраняем
        if author not in visited_authors:
            author_page = requests.get(base_url + author_link)
            author_soup = BeautifulSoup(author_page.text, "lxml")

            born_date = author_soup.find("span", class_="author-born-date").text
            born_location = author_soup.find("span", class_="author-born-location").text

            visited_authors[author] = {
                "born_date": born_date,
                "born_location": born_location
            }

        # Собираем данные в словарь
        quote_data = {
            "text": text,
            "author": author,
            "tags": tags,
            "born_date": visited_authors[author]["born_date"],
            "born_location": visited_authors[author]["born_location"]
        }

        all_quotes.append(quote_data)

    next_btn = soup.find("li", class_="next")
    page_url = next_btn.find("a")["href"] if next_btn else None

# Сохраняем всё в файл quotes.json
with open("quotes.json", "w", encoding="utf-8") as file:
    json.dump(all_quotes, file, ensure_ascii=False, indent=4)

print("✅ Сохранено", len(all_quotes), "цитат в файл quotes.json")
```
