## 📌 CSV — это что?

Это обычный текстовый файл, где данные идут **строка за строкой**, а поля разделены **запятыми или точками с запятой**:

```
text,author,tags,born_date,born_location
"Life is short","Albert Einstein","life, humor","March 14, 1879","in Ulm, Germany"
```

---

## ✅ Полный код сохранения в CSV:

```python
import requests
from bs4 import BeautifulSoup
import csv  # модуль для работы с таблицами
import json

base_url = "http://quotes.toscrape.com"
page_url = "/page/1"
visited_authors = {}
all_quotes = []

while page_url:
    response = requests.get(base_url + page_url)
    soup = BeautifulSoup(response.text, "lxml")

    quotes = soup.find_all("div", class_="quote")

    for quote in quotes:
        text = quote.find("span", class_="text").text
        author = quote.find("small", class_="author").text
        tags = [tag.text for tag in quote.find_all("a", class_="tag")]
        author_link = quote.find("a")["href"]

        if author not in visited_authors:
            author_page = requests.get(base_url + author_link)
            author_soup = BeautifulSoup(author_page.text, "lxml")

            born_date = author_soup.find("span", class_="author-born-date").text
            born_location = author_soup.find("span", class_="author-born-location").text

            visited_authors[author] = {
                "born_date": born_date,
                "born_location": born_location
            }

        quote_data = {
            "text": text,
            "author": author,
            "tags": ", ".join(tags),  # превращаем список тегов в строку
            "born_date": visited_authors[author]["born_date"],
            "born_location": visited_authors[author]["born_location"]
        }

        all_quotes.append(quote_data)

    next_btn = soup.find("li", class_="next")
    page_url = next_btn.find("a")["href"] if next_btn else None

# Сохраняем в quotes.csv
with open("quotes.csv", "w", encoding="utf-8", newline='') as csvfile:
    fieldnames = ["text", "author", "tags", "born_date", "born_location"]
    writer = csv.DictWriter(csvfile, fieldnames=fieldnames)

    writer.writeheader()  # заголовки таблицы
    for quote in all_quotes:
        writer.writerow(quote)

print("✅ CSV-файл quotes.csv успешно создан!")
```
