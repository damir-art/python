# Курс по парсингу сайтов на Python для начинающих
Где ты быстро станешь бойцом разведки уровня "взял сайт — вытащил всё". Начнём с самого простого и дойдём до уверенного навыка работы с HTML-страницами.

---

## 📚 Курс по парсингу: структура

### 🔹 Урок 0 — Подготовка

* Установка `requests`, `beautifulsoup4`, `lxml`
* Что такое HTML и DOM
* Как устроена страница

### 🔹 Урок 1 — Парсим простой сайт

* GET-запрос на страницу
* Поиск заголовков и текста
* Методы `.find()`, `.find_all()`, `.text`, `.get()`

### 🔹 Урок 2 — Поиск по классам и CSS-селекторам

* Использование `.find(..., class_=...)`
* Селекторы `.select()`
* Разбор структуры страницы через браузер

### 🔹 Урок 3 — Сохраняем данные

* Запись в `.txt`
* Запись в `.csv`
* Сохранение в `.json`

### 🔹 Урок 4 — Обработка изображений и ссылок

* Скачивание картинок
* Относительные и абсолютные ссылки

### 🔹 Урок 5 — Универсальный шаблон парсера

* Функции и повторное использование
* Парсер с аргументами
* Чтение URL из файла / командной строки

### 🔹 Урок 6 — Бонус: парсим с заголовками и `User-Agent`

* Обход антибот-защиты
* Имитация браузера
* Что делать, если `403 Forbidden`
