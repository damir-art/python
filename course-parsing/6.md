## 🎯 Цель Урока 6:

Сделать скрипт, который:

* загружает цитаты из `quotes.json` (или `quotes.csv`)
* позволяет:

  * искать цитаты по **автору**
  * находить цитаты по **тегу**
  * выводить **все уникальные теги**
  * делать это в интерактивном режиме через `input()`

---

## 🧠 Мы будем работать с `quotes.json`

(хотя можно переделать и под `CSV`, если хочешь)

---

## 🔥 Код: интерактивный фильтр JSON-файла

```python
import json

# Загружаем цитаты из quotes.json
with open("quotes.json", "r", encoding="utf-8") as file:
    data = json.load(file)

print("💬 Загружено цитат:", len(data))
print("🔍 Введите команду:")
print("1 — Найти по автору")
print("2 — Найти по тегу")
print("3 — Показать все теги")
print("0 — Выйти")

while True:
    choice = input("👉 Ваш выбор: ")

    if choice == "0":
        print("👋 Пока!")
        break

    elif choice == "1":
        name = input("Введите имя автора: ").lower()
        found = False
        for q in data:
            if q["author"].lower() == name:
                print("📜", q["text"])
                print("🏷️", q["tags"])
                print("-" * 40)
                found = True
        if not found:
            print("🙈 Ничего не найдено.")

    elif choice == "2":
        tag = input("Введите тег: ").lower()
        found = False
        for q in data:
            if tag in [t.lower() for t in q["tags"]]:
                print("📜", q["text"])
                print("✍️", q["author"])
                print("-" * 40)
                found = True
        if not found:
            print("🙈 Цитат с таким тегом нет.")

    elif choice == "3":
        unique_tags = set()
        for q in data:
            unique_tags.update(q["tags"])
        print("📦 Все теги:")
        print(", ".join(sorted(unique_tags)))

    else:
        print("⚠️ Неизвестная команда. Попробуй снова.")
```
