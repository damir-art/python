Мы пойдём дальше простого парсинга цитат и научим скрипт **переходить внутрь ссылок авторов** — как настоящий разведчик данных 🕵️‍♂️

## 💡 Цель урока:

📄 С основной страницы:
* взять имя автора и ссылку на его карточку

👤 На странице автора:
* взять дату рождения (например: *"November 29, 1898"*)
* место рождения (например: *"in Saint Paul, Minnesota, The United States"*)

## 🔥 Полный код Урока 3 с комментариями:

```python
import requests
from bs4 import BeautifulSoup

base_url = "http://quotes.toscrape.com"
page_url = "/page/1"
visited_authors = set()  # чтобы не парсить одного и того же автора несколько раз

while page_url:
    response = requests.get(base_url + page_url)
    soup = BeautifulSoup(response.text, "lxml")

    quotes = soup.find_all("div", class_="quote")

    for quote in quotes:
        # Цитата, автор, теги
        text = quote.find("span", class_="text").text
        author = quote.find("small", class_="author").text
        tags = [tag.text for tag in quote.find_all("a", class_="tag")]

        print("📜", text)
        print("✍️", author)
        print("🏷️", tags)

        # Ссылка на автора
        author_link = quote.find("a")["href"]  # пример: /author/Albert-Einstein

        # Проверим, парсили ли мы уже этого автора
        if author_link not in visited_authors:
            visited_authors.add(author_link)

            # Заходим на страницу автора
            author_page = requests.get(base_url + author_link)
            author_soup = BeautifulSoup(author_page.text, "lxml")

            # Дата и место рождения
            born_date = author_soup.find("span", class_="author-born-date").text
            born_location = author_soup.find("span", class_="author-born-location").text

            print("🎂 Родился:", born_date, born_location)

        print("-" * 50)

    # Ищем кнопку перехода на следующую страницу
    next_btn = soup.find("li", class_="next")
    page_url = next_btn.find("a")["href"] if next_btn else None
```

## ✅ Что умеет этот код:

* 💬 Парсит цитаты, авторов, теги — как раньше
* 📥 Заходит на **страницу каждого автора**
* 🧠 Не повторяет одного и того же автора (через `set`)
* 📅 Показывает дату и место рождения
