## 🧠 Код урока 1: первый парсер

```python
import requests  # библиотека для HTTP-запросов
from bs4 import BeautifulSoup  # HTML-парсер, вытаскивает нужные теги из кода страницы

url = "http://quotes.toscrape.com"  # URL тренировочного сайта с цитатами

response = requests.get(url)  # отправляем GET-запрос и получаем HTML-ответ
soup = BeautifulSoup(response.text, "lxml")  # превращаем HTML-строку в объект для парсинга

quotes = soup.find_all("div", class_="quote")  # находим все блоки <div> с классом "quote"

for quote in quotes:  # перебираем каждый блок с цитатой
    text = quote.find("span", class_="text").text  # находим сам текст цитаты внутри <span>
    author = quote.find("small", class_="author").text  # достаём имя автора внутри <small>
    tags = [tag.text for tag in quote.find_all("a", class_="tag")]  # собираем все теги (списком)

    print("📜 Цитата:", text)  # выводим цитату
    print("✍️ Автор:", author)  # выводим автора
    print("🏷️ Теги:", tags)  # выводим список тегов
    print("-" * 40)  # разделитель между цитатами
```

## Генератор списка
Разбор строки:

```python
tags = [tag.text for tag in quote.find_all("a", class_="tag")]
```

---

### 🧠 Что здесь происходит:

🔍 Расшифровка по шагам:

1. `quote.find_all("a", class_="tag")`
   — находит **внутри одного блока цитаты** (`quote`) все теги `<a>` с классом `"tag"`  
   — возвращает список объектов `tag` (например, `<a class="tag">life</a>`)

2. `for tag in ...`
   — перебираем каждый `tag` в этом списке

3. `tag.text`
   — вытаскиваем **только текст** из тега, например:
   `<a class="tag">life</a>` → `"life"`

---

### ✅ И в итоге:

```python
tags = [tag.text for tag in quote.find_all("a", class_="tag")]
```

📦 Даёт такой список:

```python
['life', 'inspirational', 'humor']
```

---

### 🔁 Эквивалент через обычный цикл:

Вот тот же код, но длиннее:

```python
tags = []
for tag in quote.find_all("a", class_="tag"):
    tags.append(tag.text)
```

Результат — тот же!
