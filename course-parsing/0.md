# ⚙️ Урок 0: Подготовка

- На диске `D:` создаю папку "python_lab"
- В папке "python_lab" создаю папку "parser"
- Открываю этот папку в VS Code
- В редакторе запускаю "New Terminal"
- В терминале пишем `python -m venv parser_env` (создастся виртуалка)
- Также создастся папка `parser_env` с содержимым
- Акивируем виртуалку: `sourсe parser_env/Scripts/activate` (для гит баш, вводить вручную или пкм)
- (parser_env) - должен появиться
- deactivate - выйти из виртуального окружения

### Устанавливаем нужные модули:

```bash
pip install requests beautifulsoup4 lxml
```

Что ты ставишь:
- requests — для HTTP-запросов
- beautifulsoup4 — для парсинга HTML
- lxml — быстрый парсер, нужен BeautifulSoup как "движок"

### Проверяем как встали модули и куда

```bash
pip list # покажет установленные модули (и зависимости)

pip show requests # должен показать путь что модуль встал внутри папки parser_env: Location: D:\python_lab\parser\parser_env\Lib\site-packages
```

Строка `Location:` показывает что модуль установлен внутри виртуалки parser_env.

## Сохраняем зависимости

```bash
pip freeze > requirements.txt
```

В корне проекта должен появиться `requirements.txt`, где располагаются имена установленных модулей с зависимостями и версиями.

Можно проверить открыв файл requirements.txt в редакторе или ввести эту команду `cat requirements.txt`

Команду `pip freeze > requirements.txt` лучше вводить в конце, когда ты:
- установил все нужные библиотеки,
- проверил, что они работают,
- готов зафиксировать "состояние проекта"

### Разворачиваем проект на новом компьютере

Копируем проект без (parser_env)

```
parser/
├── parser.py
├── requirements.txt
└── (без parser_env!)
```

- На новом компьютере переходим в папку проекта `parser`
- Создаём виртуальное окружение
- Активируем `source parser_env/Scripts/activate` # Git Bash
- Устанавдиваем зависимости: `pip install -r requirements.txt`
- Проверяем: `pip list`

### ✅ Шаг 1: Убедись, что виртуальная среда активна в терминале

### ❌ Но! VS Code НЕ использует эту среду для запуска и проверки кода.

---

### 🔧 Шаг 2: Настрой VS Code на правильную среду

1. Нажми `Ctrl+Shift+P` (или `F1`) в VS Code — откроется командная палитра.
2. Введи:

   ```
   Python: Select Interpreter
   ```
3. Выбери интерпретатор, связанный с твоей средой `seo_env`.

> Обычно он будет в пути вида:
> `.\seo_env\Scripts\python.exe`
> или
> `D:\python_lab\seo_analyzer\seo_env\Scripts\python.exe`

Если не видишь — нажми "Enter interpreter path" и выбери вручную `python.exe` из `seo_env`.
