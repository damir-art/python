# 🔹 Что такое пайп (pipe) в программировании?
В программировании **пайп** (или **pipeline**) — это **цепочка обработки данных**, где **результат одной функции передаётся в следующую**, и так далее.

> Как на заводе: данные заходят в одну трубу — проходят через фильтры и трансформации — на выходе получаешь нужный результат.

---

## 🔸 Простейшая цепочка вручную

```python
def clean(text):
    return text.strip()

def upper(text):
    return text.upper()

def exclaim(text):
    return text + "!"

result = exclaim(upper(clean("  привет, Даян  ")))
print(result)  # ПРИВЕТ, ДАЯН!
```

📦 Данные прошли три шага: очистка → капсом → добавили «!»

---

## 🔸 Используем промежуточные переменные

Если цепочка длинная, так читается легче:

```python
text = "  я люблю Python "
text = clean(text)
text = upper(text)
text = exclaim(text)
print(text)  # Я ЛЮБЛЮ PYTHON!
```

---

## 🔸 Через генераторы и `map()`

Если у тебя список данных, можно применить цепочку ко всем элементам:

```python
names = [" дима ", "аня", "   олег"]

cleaned = map(clean, names)
uppered = map(upper, cleaned)
final = list(map(exclaim, uppered))

print(final)  # ['ДИМА!', 'АНЯ!', 'ОЛЕГ!']
```

---

## 🔸 Можно сделать универсальную `pipe`-функцию

```python
def pipe(data, *funcs):
    for func in funcs:
        data = func(data)
    return data

result = pipe("  привет, Даян  ", clean, upper, exclaim)
print(result)  # ПРИВЕТ, ДАЯН!
```

💥 Просто передаёшь исходное значение и список функций — и всё работает как труба!

---

## 🔹 Где пайпы применяются?

* В **обработке данных** (например, Pandas)
* В **обработке текста**, логов, HTML, CSV
* В **нейросетях** (каждый слой — как труба)
* В **построении конвейеров данных** (`pipeline`)
* В **bash / shell** пайпы (`|`) работают по такому же принципу

## 🔸 Pipe для коллекций

Если нужно обработать список через пайп, можно сделать так:

```python
def pipe_list(data, *funcs):
    for func in funcs:
        data = list(map(func, data))
    return data

names = [" дима ", "аня", "   олег"]
result = pipe_list(names, clean, upper, exclaim)
print(result)  # ['ДИМА!', 'АНЯ!', 'ОЛЕГ!']
```

## ⚠️ Важно

- Функции применяются по порядку, слева направо.
- Для коллекций используйте map или свою pipe_list.
